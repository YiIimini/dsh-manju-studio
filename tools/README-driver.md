# manju-headless —— 无头驱动器的模块职责

`manju-headless.py` 曾经是一个 2100+ 行的单文件（历史累积）。2026-09-23 按
[docs/CONVENTIONS.md](../docs/CONVENTIONS.md) 的模块化标准拆成 `manju_headless/` 包，
**入口文件保持原路径与原名**（`tools/manju-headless.py`，现在只有 50 行薄壳），
老的脚本、文档、命令行习惯都不用改。

## 为什么拆

单文件里 89 个顶层定义挤在一起，改一处要在 2000 行里找；而它承担的能力其实分成十几类
（项目路径、ComfyUI 客户端、提示词、字幕、质检、封面、资产、分集…），彼此边界清楚。
拆开之后每个文件都能单独读、单独测，改动的爆炸半径也小了。

## 模块一览

| 模块 | 职责 | 不该放什么 |
|---|---|---|
| `paths.py` | 项目根、渲染器位置、项目目录约定（常量 + 纯路径函数） | 任何业务逻辑 |
| `jsonio.py` | JSON 读写（UTF-8） | 业务字段解释 |
| `procs.py` | 子进程执行 + 全局活动记录 `_active.json`（工作台实时日志靠它） | 具体命令的参数 |
| `comfy.py` | ComfyUI 客户端与引擎治理（健康检查 / 显存归还 / 图像模型配方 / 跑图 / 起停） | 资产业务规则 |
| `prompts.py` | 提示词片段（身份保真、构图框定、普通话锁、空间锚点） | 调用模型 |
| `series.py` | 系列资产池（跨集同一张脸；先到先得、逐字节复制） | 单集内逻辑 |
| `shots.py` | 镜头与分集的纯逻辑（集号 / 连续段 / 段内自动接镜） | IO |
| `sync.py` | 解析参考图 → `_render-<集>.json`（渲染器唯一认的输入） | 渲染本身 |
| `media.py` | 媒体工具（探测 / 切片清单 / 末帧抽取 / 片头卡） | 合成决策 |
| `subtitles.py` | 字幕（宽度 / 折行 / 时间码 / ASS，含字幕卡三类） | 合成与响度 |
| `render.py` | 构图检查（`--dry-run`）与调用渲染器 | 合成 |
| `compose.py` | 字幕 + 响度归一 + faststart 合成成片 | 渲染 |
| `qc.py` | 机械质检（时长 / 音轨 / 分辨率 / 响度 / 黑场 / 削波） | 返修决策 |
| `asr.py` | 语音转写的文本比对（相似度，不用全等 —— 同音字必错） | 转写服务调用 |
| `voice.py` | 语音验收：转写成片音轨并与剧本台词逐条比对 | 字幕生成 |
| `assets.py` | 资产定妆：Krea-2 生成定妆照与场景图（含系列池复用） | 封面 |
| `cover.py` | 独立封面（提示词 + 生成 + `cmd_cover`） | 资产定妆 |
| `project.py` | 项目级操作（状态 / `plan.json` / 分集概况 / 吸收成集 / 日志查看） | 镜头级处理 |
| `cli.py` | 命令行入口：参数解析 + 调度（**薄**） | 业务逻辑 |

依赖方向单向：`cli → 各能力模块 → paths/jsonio/procs`，没有反向 import，也没有环。

## 行为由断言锁住

拆分的唯一风险是"看着搬对了、其实改坏了"。所以先有
[`tools/driver_probe.py`](driver_probe.py)（40 条），再动结构：

- **公开面**：入口模块必须继续暴露那些函数与常量（老脚本、老文档都依赖它们）；
- **行为**：纯函数（字幕构建、接镜、集号、折行、普通话锁、封面提示词）+ 四条子命令
  （`status` / `build` / `sync` / `episodes` / `logs` / `render --dry-run`）的实际输出。

它由 `tools/manju-driver-test.mjs` 包装成闸门套件（`驱动器行为锁`），
`tools\gate.cmd` 一条命令就会跑到。

## 还能往下走的（已知）

`sync.py` / `compose.py` / `assets.py` 里的 `cmd_*` 仍把"参数解析 + 业务流程"写在一个函数里
（机械搬运的产物）。下一步可以把流程本身再抽成 `plan_sync()` / `build_film()` 这类纯函数，
让 `cmd_*` 只剩"读参数、调函数、打印"。现在不动，是因为没有测试覆盖到那个粒度之前，
先拆结构比先拆流程安全。
